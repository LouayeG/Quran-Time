# وقت القرآن

واجهة بسيطة لقراءة القرآن الكريم والاستماع إلى التلاوة.

## المزايا

- عرض جميع سور القرآن الكريم.
- قراءة النص العربي برسم عثماني.
- تشغيل السورة كاملة من شبكة القرآن الصوتية.
- تشغيل آية منفردة من شبكة القرآن الصوتية.
- البحث برقم السورة أو اسمها.

## مصادر البيانات

- نص القرآن وبيانات السور: `https://api.alquran.cloud/v1`
- ملفات الصوت: `https://cdn.islamic.network/quran`

## التشغيل

```powershell
npm install
npm run dev
```

يفتح التطبيق عادة على `http://localhost:5173`.

## البناء

```powershell
npm run build
```
